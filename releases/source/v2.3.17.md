# Jingdu v2.3.17 Source Release

version: v2.3.17
kind: source-release
google_play_production: false

This release advances Jingdu from immutable v2.3.16 with a narrowly scoped Reader page-turn performance hardening landed after the v2.3.16 hotfix. It does not change pagination source-boundary semantics, phrase-aware CJK wrapping, TTS behavior, selection behavior, dependencies, Billing, benchmark workloads, hosted/physical performance thresholds, signing policy or Google Play production status.

The exact pre-release main SHA is `af870e5daad5fd78d6ae61ec2f2558eee4fa9e4d`, the normal-merge result of PR #192. PR #192 was replayed onto immutable v2.3.16 exact-main `386c11561e8e58fb8494558be054fac44743e57d` before validation.

PR #192 removes controllable fixed costs from the paged frame path:
- selection-only StringAnnotations are excluded from the paged visual remember key while visible text, span styles and paragraph styles remain authoritative;
- when the matching worker-built page raster is already resident, paged drawing uses it directly rather than launching an empty produceState effect;
- StaticLayout line bottoms are scanned directly on the bounded page worker path instead of allocating an IntArray for every measured page;
- source contracts lock these fixed-cost properties so future regressions cannot silently restore the removed work.

The visual/selection contract remains unchanged. TTS highlight and heading styling remain represented through visual span styles, paragraph geometry remains represented through paragraph styles, and selection/touch-exploration paths still use the full selectable text path. Continuous Reader gesture/selection code is unchanged by PR #192.
