# Jingdu v2.3.17 Source Release

version: v2.3.17
kind: source-release
google_play_production: false

Jingdu v2.3.17 advances from immutable v2.3.16 with post-release Reader hardening that removes page-turn fixed costs and closes the remaining continuous first-gesture selection failure under API 36 / 200% font. The release keeps the local-TXT product scope unchanged: no dependency, Billing, benchmark workload, performance threshold/baseline/sample-floor, physical SLO, signing-policy or Google Play production-status change is included.

The exact pre-release main SHA is `1e38c0c00bbb3073b6a2de8b69a5814eabbd7c47`, the normal-merge result of PR #196. It contains the complete #192, #194 and #196 post-v2.3.16 hardening chain.

## Reader page-turn hardening

PR #192 removes controllable per-frame/per-page bookkeeping without changing source-boundary semantics:
- selection-only string annotations no longer participate in the paged visual cache key while visual span/paragraph styles remain authoritative;
- an already-resident worker-built page raster is drawn directly instead of launching an empty layout effect;
- per-page line-bottom arrays were removed from page-boundary measurement.

PR #196 adds a further semantics-preserving page-boundary optimization after retained hosted page-turn variance:
- page measurement probes `StaticLayout#getLineForVertical` at the final visible pixel to jump directly to the candidate bottom line;
- if that line is clipped, measurement backs off only as needed;
- the existing “consume only fully visible lines” contract remains unchanged;
- an oversized first line still advances so extreme accessibility text cannot deadlock paging.

## Continuous first-gesture selection hardening

PR #194 fixes the first layer of the long-press race. A real pointer held beyond Android's long-press deadline remains eligible even if a busy UI thread delays the posted timeout callback until ACTION_UP. ACTION_UP dispatches the same long-press action exactly once when the pointer is still eligible; movement, scrolling, pinch or multi-touch cancel that fallback.

PR #196 fixes the remaining selection-mapping edge case reproduced after #194. Native continuous long press maps the gesture through StaticLayout to a UTF-16 offset. At 200% font, a horizontal probe beyond the visible glyphs of a short line can land on line-ending whitespace/newline. `ReaderSelectionController.wordAt` now keeps the direct word result when available and otherwise searches a bounded 48-code-point neighborhood for nearby readable text, skipping Unicode whitespace and the Reader paragraph spacer. Large blank regions remain unselected rather than allowing a distant jump, and all source ranges continue to use the existing `SourceDisplayMap` projection.

No test timeout, gesture retry count or gesture duration was relaxed to obtain this behavior.

## Release-only scope

This release branch changes exactly three files:
- Jingdu Android default `versionCode 22 -> 23`;
- app/root `versionName` / `releaseVersion 2.3.16 -> 2.3.17`;
- this new `releases/source/v2.3.17.md` manifest.

No Reader runtime behavior is changed on the release-only branch itself.

After fresh exact-head release PR gates pass, the branch may be normal-merged only with its exact expected head.
