# Jingdu v2.3.9 Source Release

version: v2.3.9
kind: source-release
google_play_production: false

This patch release advances Jingdu from v2.3.8 after the paged Reader page-turn timing race was closed with an explicit visual-readiness generation contract. The measured workload remains six real page-turn inputs across five iterations with `FrameTimingMetric`; R8 Macrobenchmark, Baseline/Startup Profile generation, sample floors, baselines and all P95/P99 thresholds remain unchanged. This release does not claim Google Play production qualification.

The exact pre-release `main` SHA is `6d0bc44607a5f8038158d2b9941b2d012d84a703`, the normal-merge result of PR #106. PR #106 exact head `380926a68adf07eaac89f73f9c81e7d877181e87` passed CI #1492, CI Contracts #140 and Reader Performance PR #77 without changing performance thresholds. The PR hosted page-turn result was P95/P99 `69.426/76.088ms` against the unchanged `74.000/86.284ms` gates.

That exact `main` SHA passed canonical CI #1493 / run `34991519150` on attempt 1. API 36 / PAGE_SIZE=16384 functional instrumentation passed 29/29 tests, and the independent 200% font-scale `JingduUiTest` suite passed 15/15 tests. Functional evidence artifact `10406966929` has SHA256 `4a25f20f223fe1e9101676d3bbd33dd35a854a8d6830787d77ec37a1479ffe72`.

Hosted Reader performance on the exact pre-release main passed all unchanged SLOs: page-turn P95/P99 `50.637/55.442ms` against effective gates `74.000/86.284ms`; continuous-scroll P95/P99 `27.670/39.456ms` against `148.199/178.639ms`; Chapters/Settings P95/P99 `67.800/80.826ms` against `155.359/215.882ms`. R8 Macrobenchmark completed 5/5, Baseline Profile generation completed 2/2, and canonical baseline/startup profiles contain `24296 / 22992` rules. Performance evidence artifact `10406104722` has SHA256 `ed2b34ee4ea417fffe9ea98c8597b21c08f27392eeb7cf158219288b262455f8`.

The exact-main 16 KiB release packaging gate also passed. Relevant arm64-v8a and x86_64 ELF LOAD alignments are `0x4000`, the pinned NDK is `29.0.14206865`, and both the Release AAB and native-debug-symbols output were generated successfully.

The readiness fix advances `ReaderInteractionRuntime.pagedLayoutGeneration` only after the current authoritative paged layout has a resident or freshly rebuilt raster, rejects stale worker completion, and requires the benchmark fixture to observe both position progress and a new layout generation before injecting the next real tap. This prevents overlapping page-turn inputs from racing asynchronous visual publication while keeping every page-turn render frame inside the measured interval.

Repository-side Play/privacy source contracts remain fail closed, but real Google Play production qualification remains external. Production/upload signing, production AAB provenance, Play app-bundle/pre-launch validation, physical API/OEM/accessibility/performance evidence, Billing license-tester evidence, Play Console Data Safety/policy submission, store asset upload, and staged rollout/vitals evidence are not claimed by this source release.

This release-only branch changes exactly the Jingdu Android default versionCode from 14 to 15, versionName from 2.3.8 to 2.3.9, root Android releaseVersion from 2.3.8 to 2.3.9, and this source-release manifest. After fresh exact-head PR CI and Reader Performance pass, it may be normal-merged with its exact expected head. The resulting exact-main release CI must then create the annotated `v2.3.9` tag and GitHub Release, build and verify the repository-stable debug-signed APK from that immutable tag, attach `Jingdu-v2.3.9-debug-signed.apk`, `SHA256SUMS.txt` and `SIGNING-CERT-SHA256.txt`, and publish only after the release assets and provenance are complete.
