# Jingdu v2.3.13 Source Release

version: v2.3.13
kind: source-release
google_play_production: false

This patch release advances Jingdu from v2.3.12 to ship the Reader continuity fixes from PR #165. It specifically addresses paged text skipping/overlap and continuous-mode visual discontinuity or stutter at bounded-window handoff. It does not claim Google Play production qualification or physical-device TTS/Reader soak PASS; those remain external evidence tracked by #79.

The exact pre-release product main SHA is `105203a3f3f974228566452dc864bff73bfb2c07`, the normal-merge result of PR #165. PR #165 final head `c4ab5b2cfe77db95ed812c8d1983f54035e6a4ab` passed CI Contracts #366, canonical PR CI #1718 and Reader Performance PR #203. Exact-main then passed CI Contracts #367, Pose Studio #219 and canonical CI #1719.

Paged Reader navigation now advances to the exact measured source end bound to the current book revision and source start instead of applying a global mutable page-length delta. Stale asynchronous layout results are rejected by the complete layout request identity, and legitimately small measured pages remain valid instead of being inflated to a minimum source delta. This removes the skip/overlap failure mode that could make the last text on one page fail to join the first text on the next page.

Continuous Reader windows now prefer stable paragraph boundaries, preserve exact overlapping source text across handoff, and commit replacement layout geometry plus the source-anchor pixel offset atomically. The native continuous viewport can request an early handoff during fling near a bounded-window edge and resumes remaining velocity only after the replacement layout is actually installed. This prevents both source discontinuity and the periodic stop/jump effect at window boundaries while retaining the proven bounded 4 KiB steady-state window.

Regression coverage verifies current-only exact page-boundary publication, small-page continuity, paragraph-stable continuous windows, exact source overlap between adjacent bounded windows, atomic range/offset updates and proactive fling handoff only when a neighboring window actually exists.

Hosted Reader performance thresholds, frozen baselines, sample floors and physical SLO thresholds were not widened. On PR #165 exact head, Reader Performance #203 passed page-turn P95/P99 `51.145 / 61.410 ms` over 126 samples, continuous-scroll `38.996 / 53.243 ms` over 758 samples, and Chapters/Settings `85.618 / 107.197 ms` over 330 samples. The exact-main merge SHA passed canonical CI #1719 with page-turn P95/P99 `55.467 / 61.939 ms` over 135 samples, continuous-scroll `40.097 / 56.225 ms` over 766 samples, and Chapters/Settings `91.998 / 102.774 ms` over 324 samples. Canonical baseline/startup profiles contained `24897 / 23742` rules.

The final PR #165 exact head also passed Android functional instrumentation, including the real multi-window handoff overlap regression, Android build/unit/lint contracts, native-core, 16 KiB/native compatibility, terminal, Harmony, Play-store and repository-topology gates. One earlier Reader Performance attempt failed because the Android measurement guest itself crashed before producing frame metrics (`INSTRUMENTATION_ABORTED: System has crashed` with subsequent adb I/O failure); that environment failure remains retained provenance and was not treated as a product PASS.

The release-only branch changes exactly three files: Jingdu Android default versionCode `18 -> 19`, versionName `2.3.12 -> 2.3.13`, root Android releaseVersion `2.3.12 -> 2.3.13`, and this source-release manifest. No Reader behavior, dependency, benchmark workload, threshold, baseline, sample floor, physical SLO threshold, Billing behavior or release-signing policy changes in this branch.
