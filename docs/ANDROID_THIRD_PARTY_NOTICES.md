# Android production dependency inventory and notices

Jingdu treats the exact production dependency graph as release evidence. The Gradle task `:app:writeReleaseDependencyInventory` resolves `releaseRuntimeClasspath` and writes the exact transitive coordinate set to:

`apps/jingdu/android/app/build/reports/jingdu-release-dependencies.txt`

This inventory is regenerated by both `androidCheck` and `androidStoreCheck`; it is evidence, not a manually maintained substitute for the resolved graph.

## Direct production dependencies requiring attribution review

The following direct production families are intentionally present and must remain represented here when versions change:

- AndroidX Activity Compose — `androidx.activity:activity-compose:1.13.0`
- Compose BOM — `androidx.compose:compose-bom:2026.08.00` (governs Compose runtime modules)
- AndroidX Core KTX — `androidx.core:core-ktx:1.19.0`
- AndroidX DataStore — `androidx.datastore:datastore:1.2.1`
- AndroidX Room 3 — `androidx.room3:room3-runtime:3.0.3`
- AndroidX SQLite bundled — `androidx.sqlite:sqlite-bundled:2.7.1`
- AndroidX Media3 — `androidx.media3:media3-common:1.11.0`, `androidx.media3:media3-session:1.11.0`
- AndroidX Lifecycle — `androidx.lifecycle:*:2.11.0`
- AndroidX Profile Installer — `androidx.profileinstaller:profileinstaller:1.4.1`
- OpenCC Java — `io.github.laisuk:openccjava:1.4.2`
- Google Play Billing — `com.android.billingclient:billing:9.1.0`
- Google Play In-App Review — `com.google.android.play:review:2.0.2`

For every release candidate, legal/release review uses the exact resolved inventory plus the license/notice material supplied by the dependency artifacts and the checked-in third-party legal assets. The release process must not infer a license from a package name or silently drop a notice because a dependency became transitive.

## Fail-closed rule

`scripts/verify-android-third-party-inventory.py` compares production dependency declarations against this document. A new or version-changed direct production dependency must update this review record in the same change. Test/debug-only dependencies are not production package attribution entries.

The production evidence bundle retains the generated resolved inventory next to the AAB, mapping, native symbols, checksums and source provenance.
