다운로드한 TXT가 글자 깨짐으로 열리거나, 사이트 광고·워터마크가 반복되거나, 고정 폭 줄바꿈 때문에 읽기 불편하거나, 파일이 너무 큰가요? Jingdu는 로컬 장편 TXT의 어려운 문제에 집중한 리더입니다.

TXT HEALTH / 안내형 복구
• 인코딩, 텍스트 무결성, 고정 폭 줄바꿈, 장 구조, 노이즈 후보를 기기에서 검사
• 문제가 있을 때만 재디코딩, Smart Layout, Smart TOC, Smart Clean으로 바로 안내
• 진단에서 저장하는 것은 점수·개수 등 텍스트가 아닌 메타데이터뿐
• 원본 TXT 파일은 절대 수정하지 않습니다

깨진 인코딩 복구
• UTF-8, UTF-16, GB18030, GBK, GB2312, Big5 자동 감지
• AUTO가 잘못된 경우 앱의 불변 원본 사본에서 다시 디코딩
• 외부 원본 파일을 다시 찾을 필요가 없습니다

SMART CLEAN — 완전 로컬
• 반복 문장, URL, 사이트 홍보, 일반적인 워터마크/노이즈를 기기에서 스캔
• 적용 전에 정확한 텍스트, 횟수, 이유, 신뢰도를 확인
• 한 권에서 선택한 후보 적용과 Undo는 무료
• Pro는 와일드카드/전역 규칙, 여러 책 일괄 진단·적용 같은 재사용 자동화를 제공
• 외부 TXT는 그대로 유지되며 필요할 때 별도 정리된 TXT로 내보낼 수 있습니다

길고 큰 TXT를 위한 구조
• 전체 책을 하나의 거대한 관리 메모리 문자열로 만들지 않고 필요한 구간만 읽음
• 재사용 가능한 희소 인덱스로 검색, 장 이동, 다시 열기 지원
• 페이지/연속 스크롤, 전체 검색, 장, 북마크, 주석, 읽기 기록 지원

로컬 TTS
• Android에 설치된 TTS 엔진을 선택 가능
• 제공 엔진이 오프라인으로 동작하면 Piper 같은 로컬/신경망 TTS도 기기 안에서 사용 가능
• 오프라인 voice 검색·미리듣기, 속도/피치, 잠금 화면/헤드셋 제어
• Jingdu 자체는 책 본문을 서버로 전송하지 않습니다

개인정보 보호
• Jingdu 계정 불필요
• 광고 SDK 없음
• 런타임 분석/추적 SDK 없음
• Jingdu가 운영하는 본문/분석 서버 없음
• 네트워크 기능은 선택적인 Google Play Billing 및 In-App Review 흐름에만 사용되며 일반 읽기/복구는 로컬입니다

JINGDU PRO
Pro는 일회성 구매입니다. 기본 읽기와 한 권의 TXT 복구를 유료화하지 않습니다. 전역 Clean 규칙, 안전한 줄 단위 와일드카드, 일괄 진단/적용, 설치된 오프라인 TTS engine/voice 선택, 로컬 사용자 자산 백업 등 반복 작업을 줄이는 기능을 제공합니다.

현재 앱 내부 UI 언어는 중국어 간체, 중국어 번체, 영어입니다. 한국어 시스템에서는 영어 UI로 폴백합니다.
